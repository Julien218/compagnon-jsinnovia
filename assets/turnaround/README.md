# Turnaround Elyna

Ce dossier est réservé aux quatre vues canoniques destinées à Hunyuan3D MultiView.

## Vues générées

Les quatre vues ont été générées le 16 août 2026 à partir de la référence officielle `00_phenix_companion_officiel_reference.png` et des assets du kit avatar JS-Innov.IA.

Noms canoniques :

- `elyna_front.png`
- `elyna_left.png`
- `elyna_back.png`
- `elyna_right.png`

Le registre `GENERATED_ASSETS.json` contient les SHA-256 des masters, les dimensions et leur statut.

## Statut

**generated-pending-validation**

Les vues doivent encore être validées visuellement avant d'être utilisées comme source canonique pour Hunyuan3D MultiView.

## Règles de validation

- même échelle et mêmes proportions ;
- même pose neutre ;
- même design, matériaux et palette ;
- conserver les asymétries réelles ;
- ne pas déplacer le microphone par simple miroir ;
- conserver le marquage JS du casque ;
- conserver l'emblème S sur la poitrine ;
- respecter la palette iridescente des ailes et de la queue ;
- aucune vue temporaire ou miroir brut ne devient canonique.

Références : `docs/TURNAROUND_SPEC.md`, `docs/CHARACTER_SHEET.md` et `config/elyna-3d.manifest.json`.

> Les masters PNG haute résolution sont produits hors GitHub puis validés avant publication binaire définitive. Le dépôt conserve le contrat, le registre cryptographique et le pipeline de validation.
